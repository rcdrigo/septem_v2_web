# Limpeza substituída por migração

Em 23/09/2026, o usuário decidiu **preservar e converter os registros antigos**. A proposta anterior de remoção foi revogada e `reset-native-forms.py` foi desativado, inclusive para planos antigos.

Use o [procedimento de conversão manual](formularios-nativos-migracao.md). Não execute SQL de limpeza gerado anteriormente. Nenhum ambiente operacional foi limpo durante o desenvolvimento.
